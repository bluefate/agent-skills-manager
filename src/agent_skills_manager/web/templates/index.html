Skill Library

Add Skill creates a new skill folder and its SKILL.md metadata file in ~/.agents/skills/. Upload Skill imports an existing Markdown skill file into the hub. Import from GitHub fetches a linked Markdown skill file and keeps the link so you can Refresh it later. Changes here are reflected in every symlinked agent directory. Linking notes

  • Preview & Symlink moves existing skills from that agent folder into the central hub before creating the link.
  • Remove Link removes only the symlink. It can recreate an empty folder, but it does not move original skills back.
  • Restore Original appears when undo history is available and moves the skills from link creation back to the original folder.
  • Remove Location removes the location from this app’s list. It does not delete files or remove links on your computer.
  • Merge or delete conflict choices may prevent a clean automatic undo because the original copies are no longer separate.
